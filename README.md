# ანონიმო — ანონიმური შეტყობინებების საიტი 🕵️

NGL-ის სტილის ანონიმური საიტი ინსტაგრამისთვის: შექმენი შენი პირადი ლინკი, ჩასვი ბიოში ან სთორიში და მიიღე ანონიმური შეტყობინებები.

## შესაძლებლობები

- 🔗 **პირადი ლინკი** — თითოეული მომხმარებელი ქმნის საკუთარ უნიკალურ ლინკს (`/u/სახელი-xxxxx`), რომელსაც ინსტაგრამზე აზიარებს
- ✍️ **ანონიმური შეტყობინებები** — ნებისმიერს შეუძლია დაწეროს რეგისტრაციის გარეშე; ვინაობა არსად ინახება
- 💬 **ანონიმური კომენტარები** — თითოეულ შეტყობინებას ნებისმიერი სტუმარი ანონიმურად აკომენტარებს
- 🔥 **ანონიმური ჩატი** — საერთო ლაივ ოთახი (`/chat`), სადაც ყველა შემთხვევით გენერირებული ნიკით ჩატაობს (მაგ. „იდუმალი მელა #457")
- 🔒 **პირადი ინბოქსი** — ლინკის შექმნისას მფლობელი იღებს საიდუმლო ლინკს (`/inbox/სექრეთი`), საიდანაც შეტყობინებების ნახვა და წაშლა შეუძლია

## გაშვება

```bash
npm install
npm start
```

საიტი გაეშვება მისამართზე: http://localhost:3000

გარემოს ცვლადები (არასავალდებულო):
- `PORT` — პორტი (ნაგულისხმევი: 3000)
- `DB_PATH` — SQLite ბაზის ფაილის გზა (ნაგულისხმევი: `./data.sqlite`)

## ტექნოლოგიები

- **Backend:** Node.js + Express + better-sqlite3
- **Frontend:** სუფთა HTML/CSS/JS (ჩარჩოების გარეშე)
- **ბაზა:** SQLite — ცალკე სერვისი არ სჭირდება

## API

| მეთოდი | გზა | აღწერა |
|---|---|---|
| POST | `/api/profiles` | ლინკის შექმნა `{name}` → `{slug, secret}` |
| GET | `/api/profiles/:slug` | პროფილი + საჯარო შეტყობინებები კომენტარებით |
| POST | `/api/profiles/:slug/messages` | ანონიმური შეტყობინების გაგზავნა `{content}` |
| POST | `/api/messages/:id/comments` | ანონიმური კომენტარი `{content}` |
| GET | `/api/inbox/:secret` | მფლობელის ინბოქსი |
| DELETE | `/api/inbox/:secret/messages/:id` | შეტყობინების წაშლა (მხოლოდ მფლობელი) |
| GET | `/api/chat?after=:id` | ჩატის შეტყობინებები (polling) |
| POST | `/api/chat` | ჩატში წერა `{content, nickname}` |
